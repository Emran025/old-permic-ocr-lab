# بيانات المحارف البرمية القديمة الحقيقية

هذا المجلد هو **عقد فرع `real-character-dataset`** لإعداد صور المصادر الأصلية لتدريب كشف المحارف. لا يدخل أي ملف في مجموعة تدريب YOLO النهائية قبل أن يحمل وسمًا حرفيًا معتمدًا وسجل مصدر وقرار حقوق واضح.

| الطبقة | المحتوى | هل تدخل تدريب YOLO؟ |
|---|---|---|
| `source_manifest.json` | فهرس كل الصور الأصلية المستضافة وحقوقها وحالة المراجعة | لا |
| `work/raw/` | نسخ عمل مطابقة للمصدر خارج مشروع الموقع | لا |
| `work/crops/` | قصاصات مناطق كتابة مع معرفات مصدر وإحداثيات أصلية | لا، حتى اعتمادها |
| `annotations/character_instances.jsonl` | صناديق المحارف وUnicode ومرجع القراءة | نعم، بعد حالة `verified` فقط |
| `exports/yolo/` | صور ووسوم YOLO المصدّرة من السجلات المعتمدة | نعم |

> القاعدة الحاكمة: صندوق المنطقة ليس وسم محرف. لا يُستنتج اسم حرف أو رمز Unicode من التشابه البصري وحده. يلزم لكل حرف قراءة مرجعية أو اعتماد باحث لغوي، مع ربطه بالقصاصة والصورة الأصلية.

## مسار العمل

1. تُنزّل النسخ العاملة من الروابط المصرح بها إلى مساحة خارج المشروع.
2. تُنشأ قصاصات مناطق الكتابة مع إحداثياتها على الصورة الأصلية من دون تحسين أو تعديل دلالي.
3. يُراجع الباحث القراءة، ثم تُسجّل صناديق المحارف منفردة بترميز Unicode `U+10350–U+10375` وحالة `verified`.
4. يُصدَّر فقط السجل المعتمد إلى صور ووسوم YOLO، مع تقسيم يمنع تسرب القصاصات من المصدر نفسه بين التدريب والاختبار.

لا تُضاف المواد السياقية أو الصور الشارحة أو أي مصدر مقيد الحقوق إلى `exports/yolo/`.
